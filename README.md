# Username Finder

A simple JavaScript project that searches for usernames and displays the results using data fetched from an API.

## Features

* Search for usernames
* Uses the Fetch API to retrieve data
* Built with Async/Await for asynchronous operations
* Displays fetched results dynamically
* Beginner-friendly project focused on learning API integration

## Technologies Used

* HTML
* CSS
* JavaScript
* Fetch API
* Async/Await

## What I Learned

This project was created to improve my understanding of:

* Making API requests with Fetch
* Working with Async/Await
* Handling JSON responses
* Error handling in asynchronous code
* Updating the DOM with fetched data

## Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project folder.

3. Run the project using Live Server or open `index.html` in your browser.
